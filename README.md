# 📝 Task Manager CLI

Sim, eu sei que existem milhões de gerenciadores de tarefas por aí, especialmente em Python.

**Mas por que não criar mais um?**

Afinal, o mundo claramente precisava de outro Task Manager rodando no terminal.

## 🧠 Entendendo o projeto

### 🤔 Qual é o diferencial em relação aos outros?

**Resumindo: nenhum!**

Estou aprendendo a programar em Python (**SEM IA**) e pensei:

> "Por que não fazer um projeto extremamente batido, que provavelmente já foi desenvolvido por qualquer pessoa que tenha passado mais de três dias aprendendo Python?"

Dito e feito.

Aqui está mais um Task Manager para aumentar a coleção de projetos que absolutamente ninguém pediu.

**Mas pelo menos fui eu que escrevi.** E isso já é alguma coisa (meio que fodasse né).

## ⚙️ Features

Tecnologia de ponta para resolver problemas que um pedaço de papel também resolveria.

| Feature | O que faz |
| :--- | :--- |
| ➕ **Adicionar tarefas** | Adiciona tarefas. Revolucionário. |
| 📋 **Listar tarefas** | Lista as tarefas que você provavelmente vai procrastinar. |
| ✅ **Concluir tarefas** | Permite fingir que sua vida está organizada. |
| 🗑️ **Remover tarefas** | Apaga tarefas como se elas nunca tivessem existido. |
| 🚪 **Sair** | Encerra o programa. Às vezes, desistir é uma feature. |

## 🎯 Objetivo

O objetivo deste projeto não é reinventar a roda.

É simplesmente aprender Python na prática, entender a lógica por trás do código e conseguir desenvolver alguma coisa sem pedir para uma inteligência artificial fazer tudo por mim.

**Se funcionar, ótimo. Se quebrar, aprendizado. Se eu não souber por que funcionou, temos um problema.**
